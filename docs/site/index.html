GET STARTED

Make room for later.

TabCarry is ready for local installation. A Chrome Web Store listing is not available yet.

  1. 01

    Download & unzip

    Download v{{version}} and extract the ZIP into a folder you’ll keep.

  2. 02

    Load in Chrome

    Open chrome://extensions, turn on Developer mode, then choose Load unpacked and select the extracted folder.

  3. 03

    Save your first session

    Pin TabCarry to the toolbar. Click it, choose your save scope and save. Your current tabs stay open.

Already installed? Keep the same extension folder and replace its files before reloading. Export a backup before uninstalling or moving to another profile.

A FEW GOOD QUESTIONS

Before you start.

What does a session include?

Page titles and full URLs, window structure, tab order, pinned and active tabs, and tab-group names, colors and collapsed state. TabCarry does not save page contents, unsent forms, cookies, login sessions, scroll positions or media progress.

Can I use it offline?

You can save and manage the tab information already available in your browser while offline. Loading saved websites may need an internet connection. Only HTTP and HTTPS pages reopen automatically; other saved URLs can be copied manually.

What happens if I uninstall it?

Local extension data can be removed. Export an independent JSON backup first. You can later import that backup into TabCarry. Backup files contain full URLs and titles, so keep them private.

Does saving close my tabs?

Ordinary Save leaves tabs open. Save and close is a separate action with a confirmation. TabCarry writes the snapshot before closing eligible tabs; it cannot preserve unsent form input.
